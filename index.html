El problema

El cuello de botella está en cómo se busca

Cada escaneo dispara una búsqueda: ese diseño define la fila en caja.

búsqueda lineal lista
búsqueda binaria doble ABB

Búsqueda lineal: recorre la lista hasta dar con el código. Con un millón de productos, el peor caso son un millón de comparaciones.

Con el ABB: cada comparación descarta una rama completa. El peor caso baja a unas 20 comparaciones.

Concepto

Un catálogo, dos índices, cero duplicación

Índice principal — clave: código de barras (escáner) Nodo = clave + referencia · los datos pesados viven una sola vez Índice secundario — clave: nombre (plan B sin lector)

    function claveDe(nodo, modo) {
  return modo === 'num'
    ? nodo.codigo
    : CATALOGO[nodo.codigo].nombre.toLowerCase();
}

function comparar(objetivo, clave, modo) {
  var a = modo === 'num' ? String(objetivo) : String(objetivo).toLowerCase();
  var b = modo === 'num' ? String(clave) : String(clave).toLowerCase();
  if (b.indexOf(a) === 0) return 0;
  if (a < b) return -1;
  if (a > b) return 1;
  return 0;
}
    function planificarBusqueda(modo, valor) {
  var pasos = [];
  var actual = 'root';
  var objetivo = modo === 'num' ? valor : valor.toLowerCase();
  while (actual) {
    var nodo = NODO_POR_ID[actual];
    var clave = claveDe(nodo, modo);
    var cmp = comparar(objetivo, clave, modo);
    var siguiente = cmp < 0 ? nodo.izq : (cmp > 0 ? nodo.der : null);
    var lado = cmp === 0 ? 'hallado'
      : (siguiente ? (cmp < 0 ? 'izquierda' : 'derecha') : 'sin coincidencia');
    pasos.push({
      id: nodo.id, clave: clave, cmp: cmp,
      prefijo: cmp === 0 && clave.toLowerCase() !== objetivo,
      siguiente: siguiente, lado: lado
    });
    if (cmp === 0) {
      return { modo: modo, valor: valor, pasos: pasos, ok: true, codigo: nodo.codigo };
    }
    actual = siguiente;
  }
  return { modo: modo, valor: valor, pasos: pasos, ok: false, codigo: null };
}
    function prepararBusqueda(valor) {
  var cant = caracteresValidos(valor);
  if (cant < 3) { marcarError(mensajeCorto(cant)); return; }
  var modo = /^\d+$/.test(valor) ? 'num' : 'nom';
  planActual = planificarBusqueda(modo, valor);
  pasoActual = 0;
  pintarPaso(0);
  setEstado('pausado · paso 1 de ' + planActual.pasos.length);
}

function avanzar() {
  if (!planActual || pasoActual >= planActual.pasos.length - 1) return;
  pasoActual += 1;
  pintarPaso(pasoActual);
  setEstado('paso ' + (pasoActual + 1) + ' · de ' + planActual.pasos.length);
}
    Datos del simulador
    Complejidad

    Una comparación por nivel del ABB: O(log n). Con 1.000.000 de productos, unos 20 saltos.

    Memoria

    NODOS guarda dos referencias izq / der; CATALOGO guarda cada producto una sola vez. Ambos índices apuntan al mismo objeto.

    Doble índice

    La misma forma de árbol cambia la clave con claveDe(nodo, modo). El plan guarda un array pasos: cada toque de «paso →» muestra una comparación.

    Riesgo y cierre

    El ABB solo es rápido si se mantiene balanceado

    Balanceado
    Degenerado

    Balanceado: cada nivel divide el conjunto en dos y la altura crece como log₂ n. Con un millón de productos, unos 20 saltos.

    Degenerado: si las claves llegan ordenadas, el árbol se estira en una lista y la búsqueda vuelve a ser O(n). La forma importa tanto como el algoritmo.
